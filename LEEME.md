# Escáner

App Android (Kotlin + Compose) para escanear y gestionar documentos: escáner ML Kit con detección de bordes, recorte manual con lupa, filtros (Original, Documento, Grises, Magic Color), mesa de trabajo con reordenamiento y exportación a PDF y Word.

Cada push a `main` compila el APK en GitHub Actions y lo publica en Releases (`Escaner.apk`).
